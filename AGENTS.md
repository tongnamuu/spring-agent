# Project Instructions

## Jira

- Use `$jira-ticket-workflow` only when explicitly instructed to create or reference Jira tickets.

## GitHub

- Use the authenticated `gh` CLI for all GitHub operations in this repository.
- Do not use GitHub plugin, app, or connector tools.
- Creating or updating a pull request never authorizes merging it.
- Before every pull request merge, stop and obtain explicit user approval for that specific PR. Do not infer approval from earlier requests such as "finish", "complete", or "create a PR".
